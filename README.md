# Exploratory Data Analysis (EDA) – Sample Superstore

## 📌 Overview

This project is completed as part of the **Veda Technologies Data Analytics Internship**. The objective of this task is to perform Exploratory Data Analysis (EDA) on the Sample Superstore dataset and identify meaningful patterns, relationships, trends, and outliers using Python-based data analysis and visualization techniques.

## 🎯 Objectives

- Understand and inspect the dataset
- Perform data cleaning and preprocessing
- Generate summary statistics using Pandas
- Analyze correlations between numerical variables
- Identify trends and patterns in the data
- Detect potential outliers
- Analyze Sales and Profit across different categories and regions
- Generate meaningful business insights

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Analysis Performed

The project includes:

1. Dataset inspection and understanding
2. Missing-value and duplicate-value analysis
3. Descriptive statistical analysis using `.describe()`
4. Correlation analysis using a heatmap
5. Sales distribution analysis
6. Category-wise Sales and Profit analysis
7. Sales vs Profit relationship analysis
8. Outlier detection using boxplots
9. Monthly Sales trend analysis
10. Regional Sales and Profit analysis
11. Discount vs Profit analysis

## 📈 Visualizations

The analysis uses multiple visualization techniques, including:

- Histograms
- Bar Charts
- Scatter Plots
- Boxplots
- Line Charts
- Correlation Heatmaps

Each visualization is supported by observations explaining the patterns identified from the data.

## 🔍 Key Insights

The analysis helps identify important business patterns related to:

- Sales and profitability
- Product category performance
- Regional performance
- Discount and profit relationships
- Sales trends over time
- Unusual or extreme observations
